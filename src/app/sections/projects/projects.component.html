Horse Race Game

A fun horse racing game where players place bets and watch the action unfold in real-time. I built this to learn how desktop applications work with databases - every race result gets saved to MySQL.

The biggest challenge was making the JavaFX interface feel lively and keeping the game data in sync. It was my first deep dive into real-time updates.

Built with: Java, JavaFX, MySQL.
